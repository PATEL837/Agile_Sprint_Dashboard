Create a separate static client-facing overview page at:
`overview/index.html`
Directory structure:

```text
dashboard/index.html
data/agile_dashboard_data.json
overview/index.html

```

Requirements

* `dashboard/index.html` remains the full editable dashboard with all tabs, controls, data entry, and functionality.
* `data/agile_dashboard_data.json` remains the single source of data.
* `overview/index.html` must be a read-only/static presentation page for clients.
* The client will access only the `overview/index.html` website link.
* No data entry, editing, import/export, or administrative controls should appear on the overview page.
* The overview page should automatically read and display the data from `data/agile_dashboard_data.json`.
* Any updates made through `dashboard/index.html` and saved to the JSON file should automatically appear when the client reloads `overview/index.html`.
* The overview should use the same visual design, charts, KPIs, and key information currently available in `dashboard/index.html`, but remove anything intended only for internal editing/management.
* Keep the client view clean, professional, simple, and presentation-ready.
* Do not duplicate or maintain a separate dataset for the overview page.

Important: The goal is to have one editable dashboard → one shared JSON data source → one read-only client overview, so there is no need to manually update the client page.
