Data Backup & Transfer

Use Export on your phone, then Import the downloaded file on your PC. This is the Stage 1 way to move data between devices.
Export includes sprint setup, tasks/PBIs, daily updates, and historical velocity. Export JSON or Export Excel both produce a full backup you can re-import here, or commit into the data directory (as agile_dashboard_data.json / .xlsx, sibling of dashboard) for GitHub Pages to pick up automatically. Import File accepts a full-backup .json, a full-backup .xlsx (same sheet layout as Export Excel), or a single table .csv (Tasks/Velocity/Daily/Sprint Plan CSV - matched automatically by its column headers and merged into that table).

CSV Export

Useful for opening single tables in Excel/Sheets. Each can also be re-imported via Import File.

This permanently clears all locally stored dashboard data.
