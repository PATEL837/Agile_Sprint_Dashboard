Save Data

First click: pick your data/agile_dashboard_data.json file once to link it — browsers require this one-time permission step and won't let a page write to disk silently. After that, this dashboard remembers the link (even after reloading the page), and every "Save Data" click overwrites that exact file with no dialog. Reloading the dashboard also reads back from that same linked file, so what you see always matches what's on disk.

Data Backup & Transfer

Use Export on your phone, then Import the downloaded file on your PC. This is the Stage 1 way to move data between devices.
Export includes sprint setup, tasks/PBIs, daily updates, and historical velocity. Export downloads as agile_dashboard_data.json — commit it into the data directory (sibling of dashboard) for GitHub Pages to pick it up automatically.
